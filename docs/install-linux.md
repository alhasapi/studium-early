# Linux installation

Install Luanti from your distribution or from [luanti.org](https://www.luanti.org/). Close Luanti, then from the Studium directory run:

```sh
./install.sh
```

The installer uses `~/.local/share/luanti/mods` when present and otherwise `~/.minetest/mods`. Start Luanti, select a world, and run `/edu_menu`.
