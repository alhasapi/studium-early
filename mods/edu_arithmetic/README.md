# edu_arithmetic

An arithmetic kiosk for reading and typing practice, with addition and
subtraction questions using numbers from 0 to 10.

Place the **Arithmetic Learning Kiosk**, or use `/edu_kiosk` while testing.

## Where this fits

This is the only Studium activity that is not in the child toolbox, on purpose.
It asks a child to read a question and type an answer, while Studium's
block-first activities are designed so a non-reader can play from pictures,
blocks and sound alone. The kiosk is kept for older children, teachers, and for
testing progress storage, and is reached through `/edu_kiosk` or its crafting
recipe rather than the toolbox.

`edu_number_blocks` is the arithmetic activity a child is meant to meet first.

This is also the only mod that needs Minetest Game (`default:wood`,
`default:book`, and its sounds). The other Studium mods depend only on
`edu_core` and run on any game.
